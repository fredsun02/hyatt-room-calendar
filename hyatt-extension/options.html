Settings

Calendar

Open a Hyatt hotel page and click Room calendar in the lower-left corner.

For incognito windows, enable “Allow in incognito” in this extension’s browser settings.

If you used the previous version, disable the Hyatt userscript and separate Cookie Helper, then reload your Hyatt tabs.

Data

Results are saved in this browser. Clearing Hyatt cookies keeps them; uninstalling the extension removes them.

Import backup

Stop active scans before importing. Records are merged by date, keeping the newer result. Importing does not start a scan. Reload Hyatt tabs when finished.
Moving from the userscript

Update the existing userscript to 0.13.0 or later and export a backup from its calendar. Disable the userscript, then import that JSON file here.

Local backup

Optional. Connects to the local service at 127.0.0.1:8787 to reuse older data or share results between browser profiles. Enabling it requests local access permission.

After enabling, reload a Hyatt tab and select a hotel to load its saved results.

Background collection

Keeps a pinned Hyatt tab open and refreshes points calendars and cash inventory for the hotels below, one request at a time, through your own Hyatt session. Points calendars refresh daily; cash dates refresh daily up to 30 days out, every 3 days up to 120 days and weekly after that. Collection pauses while you run a scan and backs off when Hyatt blocks requests. Results are saved to hryv-store, so Connect to hryv-store must be on.

Keep Chrome open. To stop, turn collection off here; closing the pinned tab only pauses it for five minutes.
